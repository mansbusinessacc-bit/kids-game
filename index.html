Голос

Голоса берутся из телефона. Чтобы появился голос получше:
iPhone: Настройки → Универсальный доступ → Устный контент → Голоса → Русский → скачать «Милена (улучшенный)».
Android: Настройки → Синтез речи (или «Преобразование текста в речь») → Синтезатор речи Google → Установить голосовые данные → Русский.
Потом перезапустите игру и выберите голос здесь.
